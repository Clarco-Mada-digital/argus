Trois façons de l'utiliser

1. Dans le navigateur, sans rien installer

Ouvrez l'analyseur, choisissez un dossier de votre ordinateur, et le rapport s'affiche. Vos fichiers ne quittent pas votre machine — la page n'a pas de serveur.

Le sélecteur de dossier demande Chrome, Edge ou Opera. Les autres navigateurs utilisent un champ de fichiers classique, qui fonctionne aussi.

2. En ligne de commande, sans cloner

npx github:Clarco-Mada-digital/argus scan ./mon-projet

Node.js 18 ou plus récent, rien d'autre. C'est la voie complète : rapports SARIF, mode différentiel, correctifs assistés, exploration HTTP.

3. Dans votre intégration continue

- uses: Clarco-Mada-digital/argus@main
  with:
    since: origin/${{ github.base_ref }}
    fail-on: medium
Rien n'est envoyé nulle part. L'analyse est entièrement locale. Deux commandes optionnelles peuvent utiliser le réseau — sync (base de vulnérabilités OSV) et crawl (audit d'un site en ligne) — et elles ne transmettent jamais votre code.

Ce qu'il trouve

Sécurité

Secrets versionnés, injections SQL et commandes, XSS, désérialisation, cryptographie faible. Chaque constat porte son CWE et sa catégorie OWASP.

Routes mortes

Liens internes qui ne mènent nulle part, pages orphelines, routes déclarées deux fois, page 404 absente.

Code mort

Fichiers jamais importés, exports inutilisés, code inatteignable, restes de débogage.

SEO

Balises, hiérarchie des titres, données structurées, robots.txt, sitemap — et les applications qui servent une page vide aux robots.

Accessibilité

Contrastes WCAG calculés, avec une couleur de remplacement proposée. Libellés, navigation clavier, responsive.

Dépendances

Vulnérabilités réelles via OSV.dev, scores CVSS calculés, paquets abandonnés.

Frameworks reconnus

Six packs de règles dédiés, chacun validé contre un projet réaliste avant livraison :

FrameworkExemple de ce qu'il attrape
DjangoSECRET_KEY en dur, formulaire sans {% csrf_token %}, {% url %} vers une route inexistante
Laravelenv() hors de config/ — renvoie null après config:cache
Railsconfig/master.key versionné, interpolation dans un where()
SpringActuator ouvert : /heapdump expose tous les secrets en mémoire
Expressdotfiles: 'allow' qui sert .env et .git
Next.jsNEXT_PUBLIC_*_SECRET — inlinée dans le bundle du navigateur

Langages

JavaScript, TypeScript, Python, Java, Kotlin, Dart, PHP, Go, Ruby, C#, Rust, HTML, CSS — et les gabarits Blade, ERB, Twig et Jinja.

Limites

Argus fait de l'analyse statique et lexicale : il ne construit pas d'arbre syntaxique complet et n'exécute pas votre code. Les constats marqués « tentative » demandent une lecture humaine, le code chargé dynamiquement peut être signalé à tort comme mort, et les liens construits à l'exécution ne sont pas résolus. C'est le prix d'un outil qui s'exécute en une seconde, sans rien installer.
